# 액션 플랜: 12주 실행 로드맵

전략서(`01_전략서_어필리에이트_양성전략.md`)의 4대 축(Literacy / Incentive / Community / Tooling / Localization)을 실행 가능한 주차별 태스크로 분해한다. 담당: 그로스해킹(SNS·인플루언서/어필리에이트) 1인 기준, 필요 시 협업 부서 표기.

## Phase 0 — 기반 구축 (Week 1-2)

| 태스크 | 산출물 | 협업 |
|---|---|---|
| 쇼피파이 주문 + 업프로모트 성과 데이터 export | CSV 2종 | - |
| 2,000명 세그멘테이션 (Tier 0~4 자동 태깅) | 통합 크리에이터 시트 | - |
| **Creator Hub MVP 구축** (본 저장소 `creator-hub/`) | 크리에이터 포털 + 운영자 콘솔 | 개발(본인이 직접 코딩/검증) |
| 아카데미 커리큘럼 5강 초안 작성 | 모듈 텍스트 | - |

**완료 기준**: 2,000명 전원이 Tier 0~4 중 하나로 분류되어 있고, Creator Hub에서 CSV 업로드 시 자동 분류가 재현됨.

## Phase 1 — 아카데미 & 온보딩 런칭 (Week 3-4)

- 아카데미 5강 Creator Hub에 게시 (링크 활용법 / 콘텐츠 CTA / EU 광고표시 규정 / K-뷰티 콘텐츠 포맷 / 성과 확인법)
- 전원 대상 온보딩 이메일 시퀀스 발송 (Tier 0 재활성화용 별도 문구)
- 웰컴 미션 배포: "아카데미 1강 수료 + 프로필 완성" → 즉시 소액 리워드
- **KPI 체크포인트**: 아카데미 1강 수료율 ≥ 30%

## Phase 2 — 인센티브 & 게이미피케이션 (Week 5-8)

- 티어 시스템 크리에이터에게 공개, 승급 기준 투명화
- 마일스톤 보너스 규칙 확정 및 지급 프로세스(업프로모트 커미션 룰 연동) 수립
- Tier 3 승급자 대상 PR 키트 선지급 파일럿 (국가별 20명)
- 리더보드 공개 (Creator Hub 상)
- **KPI 체크포인트**: Tier 1→2 승급 인원 전월 대비 +50%

## Phase 3 — 로컬 커뮤니티 구축 (Week 9-12)

- 언어권별(DE/FR/EN) 커뮤니티 채널 개설
- 국가별 로컬 앰버서더 3~5명 위촉 (Tier 4 중 선발)
- 로컬라이즈드 콘텐츠 브리프 배포 (국가별 시즌 이슈 반영)
- **KPI 체크포인트**: 커뮤니티 채널 참여율, 로컬 앰버서더 발신 콘텐츠 수

## Phase 4 — 지속 최적화 (Week 13~, 상시)

- 월간 코호트 리텐션 분석 (Creator Hub 데이터 기반)
- 인센티브 구조 A/B 테스트 (커미션율 vs 마일스톤 보너스 vs 제품 시딩)
- 틱톡샵 대안 채널(LTK, ShopMy, Shopify Collabs) 파일럿 검토
- 아카데미 콘텐츠 v2 (Tier 3/4 대상 심화 모듈 — 광고 집행, 콜라보 협상법)

---

## 실행 우선순위 원칙

1. **채용보다 육성**: 신규 어필리에이트 모집 예산·시간을 기존 2,000명 활성화에 먼저 투입한다.
2. **작게 시작해 반복**: 국가 1~2곳, 20~50명 파일럿으로 검증 후 확대한다.
3. **모든 액션은 Creator Hub에 데이터로 남긴다**: 수기 관리로 되돌아가지 않도록, 세그먼트/미션/성과 확인은 반드시 Hub를 경유한다.
