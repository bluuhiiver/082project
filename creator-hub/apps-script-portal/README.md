# 크리에이터 본인용 포털 — Apps Script 배포 패키지

유럽 크리에이터들이 직접 쓰는 셀프서브 포털(온보딩 체크리스트 · 아카데미 5강 · 미션 · 내 성과 대시보드 · 링크/코드 생성기 · 리더보드)을 Apps Script 웹앱으로 배포하기 위한 패키지다.

**운영 사이트(내부용 "Piyonna Creator Pool")와 반드시 별도 프로젝트로 배포한다.** 운영 사이트는 카카오스타일 계정 전용이라 외부 크리에이터가 접속할 수 없고, 이 포털은 반대로 누구나 접속해야 하기 때문이다. 별도 프로젝트로 나누면 접근 권한도 자연히 분리된다.

## 배포 방법 (10분, 최초 1회)

1. [script.new](https://script.new) 접속 → 새 Apps Script 프로젝트 생성, 이름은 "Piyonna Creator Portal" 등으로
2. 기본 생성된 `Code.gs` 내용을 이 폴더의 `Code.gs`로 교체
3. 파일 추가(+) → HTML → 이름 `Index` → 내용을 이 폴더의 `Index.html`로 교체
4. 배포 → 새 배포 → 유형: **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** ← 크리에이터는 구글 계정이 없을 수 있으므로 필수
5. 발급된 `/exec` URL이 크리에이터들에게 공유할 영구 주소다

이후 수정할 때는 파일 고치고 "배포 관리 → 새 버전"만 누르면 URL 유지된 채 갱신된다.

## 데이터가 어디에 저장되나

**서버에는 아무것도 저장되지 않는다.** 이메일, 아카데미 진도, 미션 상태는 전부 각 크리에이터 본인 브라우저(localStorage)에만 남는다. 그래서 GDPR 부담 없이 바로 공개 배포할 수 있는 대신, 다음 한계가 있다:

- 크리에이터가 기기를 바꾸면 진도가 초기화된다
- 리더보드/내 성과에 실제 매출 데이터가 없다 (빈 상태로 표시)

## 다음 확장: 실성과 연동

운영 사이트(Code.gs)의 `fetchUpPromoteGmv()` 패턴을 재사용해 이 프로젝트에 `getMyStats(email)` 서버 함수를 추가하면, 크리에이터가 로그인한 이메일 기준으로 본인의 실제 클릭/주문/커미션을 보여줄 수 있다. 이때 주의점:

- UpPromote API 키는 반드시 Script Properties에 저장 (코드에 하드코딩 금지)
- 이메일만 알면 남의 성과를 조회할 수 있게 되므로, 확장 시 매직링크 이메일 인증(본인 메일로 받은 링크로만 로그인)을 함께 붙이는 것을 권장
- 리더보드는 이름을 이니셜 처리해 노출

## 검증

Playwright(모바일 390px 뷰포트)로 가입 → 아카데미 수료 → 코드 저장/링크 생성 → 미션 → 리더보드 빈 상태까지 확인, 콘솔 에러 0건. 운영자 콘솔로 가는 링크는 크리에이터에게 노출되지 않도록 제거했다.
