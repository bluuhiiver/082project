이 콘솔은 크리에이터의 이메일·성과 데이터를 다룹니다. 실제 데이터를 사용할 경우 인증 없이 공개 URL(GitHub Pages 등)에 배포하지 말고, 내부망 또는 접근 제한이 걸린 환경에서만 운영하세요. 자세한 내용은 README를 참고하세요.

1. 데이터 가져오기

구글시트에서 파일 → 다운로드 → CSV로 내려받아 올리면 Handle ID·채널·팔로워·협업 이력이 이메일 기준으로 병합됩니다.
